# 2026.269.0926 — fix(build): cleanStaleBuildDirs preserves a concurrent bed's .build dir

## Summary of changes

Fix the roster image-build race: `cleanStaleBuildDirs` removed a **concurrent
bed's** in-progress `.build/<box>` directory.

### RCA (8-step, evidence)
**Unexpected.** In a `charly check run check-all-beds` roster, many beds' image
builds failed `podman build exit 125` on a `COPY .build/<box>/…` — but the SAME
build succeeds standalone.

**Mechanism.** `cleanStaleBuildDirs` removes every `.build/<dir>` not present in
THIS build's `resolved` map. The roster runs many beds as goroutines in ONE process
sharing one `.build/`; a sibling bed is absent from this build's scoped closure
(and namespaced box dirs are absent from the root-scope `resolved` set at all), so
its in-progress dir is deleted mid-COPY.

**Evidence (BEFORE — pre-fix roster, calver 2026.268.2326):**
```
$ grep -l "Removed stale build dir" .check/*/2026.268.2326/image-build.log | wc -l
3
$ grep -l "exit status 125" .check/*/2026.268.2326/image-build.log | wc -l
5
# a sibling bed's log names the culprit box:
$ grep "Removed stale build dir" .check/charly.arch.check-tmux-pod/*/image-build.log
Removed stale build dir: .build/charly.docs-site-app
```

### Fix
Preserve any dir whose name resolves to an enabled box anywhere in the config
(`cfg.ResolveBoxRef(name)`); only a genuinely-unknown box name is stale.

### Evidence (AFTER — same 128-bed roster with this fix, calver 2026.269.0559)
```
$ grep -l "Removed stale build dir" .check/*/2026.269.0559/image-build.log | wc -l
0
$ grep -l "exit status 125" .check/*/2026.269.0559/image-build.log | wc -l
0
$ charly version
2026.269.0132
$ grep -E "roster —" roster.log
charly check run check-all-beds: roster — 128 bed(s) selected, 12 refused (host-local)
```

### The OTHER failure in that after-run is a NAMED batch: RCA-G / plugin-dsh#7 + plugin-agentteams#5
The remaining image-build failures in the after-run are `plugin.source: builtin` in
two pinned plugin candies (a retired schema field). That is **plan RCA-G**, fixed in
its own immediate-next batch — **plugin-dsh#7** and **plugin-agentteams#5** (each:
`source: builtin` → the module path, `charly box validate` exit 0). This PR does not
own that fix; the G batch is named and in flight.

### Tests
`TestCleanStaleBuildDirs_PreservesConcurrentBedsBoxDirs` — a namespaced sibling box
dir survives; a genuinely-unknown dir is removed.
