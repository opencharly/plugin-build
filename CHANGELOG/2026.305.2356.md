## Summary

Adopt `github.com/opencharly/sdk v0.2026305.2312` (opencharly/sdk#478, squash `8656f7d`, tag `v0.2026305.2312`).

That sdk release makes `deploykit`'s candy COPY source origin-driven: a candy declared in an **imported namespace** is marked `Remote` and staged under `.build/_candy/<name>.<version>/`, instead of emitting the project-relative `candy/<name>/` that an importing project cannot have (opencharly/.github#263 item (b)).

plugin-build's staging is already keyed on `GetRemote()` — `candy/plugin-build/host_prep.go:144,165` — so this module needs only the pin bump. `go mod tidy` also moves the transitive `spec` pin (`v0.2026295.2356` -> `v0.2026296.1036`), the version sdk's own requirement carries.

No source change: 2 files (`go.mod`, `go.sum`).
